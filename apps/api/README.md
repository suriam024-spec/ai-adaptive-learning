# AI Adaptive Learning API

NestJS backend scaffold สำหรับ MVP

## Run

```bash
pnpm install
pnpm dev
```

API:
- GET http://localhost:3001/api/health
- GET http://localhost:3001/api/courses
- GET http://localhost:3001/api/learning/next
- GET http://localhost:3001/api/learning/path
- POST http://localhost:3001/api/auth/login
- POST http://localhost:3001/api/ai/tutor

ข้อมูลตอนนี้เป็น mock data เพื่อให้ Frontend เชื่อมได้ก่อน
